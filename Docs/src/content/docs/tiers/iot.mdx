## Tier Summary

**Basic** provides the core operational view of IoT devices: current device status, basic sensor data, 30 days of data history, manual fault reporting, basic email alerts, standard data export, map view, and business-hours support.

**Advanced** extends Basic with configurable alerts and threshold values, remote device management and diagnostics, map actions and view, 12 months of data history, and advanced reports and analytics.

**Pro** extends Advanced with unlimited data history, sub-tenant organization units, custom dashboards and reports, usage reports, priority technical support, and agreed response times in accordance with the SLA.
