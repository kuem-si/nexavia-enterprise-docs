<div class="tier-hero">
	<p>IoT tiers define the level of device status visibility, sensor data history, alerting, diagnostics, reporting, dashboards, and support included for IoT deployments.</p>
</div>

<div class="tier-grid">
	<div class="tier-card tier-basic">
		<h2>Basic</h2>
		<p><strong>Choose this when:</strong></p>
		<p>You need a clear operational view of current device status, recent sensor data, map visibility, and basic alerting.</p>
	</div>
	<div class="tier-card tier-advanced">
		<h2>Advanced</h2>
		<p><strong>Choose this when:</strong></p>
		<p>You need active device management, configurable alerts, diagnostics, advanced reports, and longer data history.</p>
	</div>
	<div class="tier-card tier-pro">
		<h2>Pro</h2>
		<p><strong>Choose this when:</strong></p>
		<p>You need tenant segmentation, custom dashboards, unlimited history, usage reporting, and SLA-backed priority support.</p>
	</div>
</div>

## What Each Tier Adds

<div class="tier-grid">
	<div class="tier-card tier-basic">
		<h3>Basic</h3>
		<ul>
			<li>Current device status</li>
			<li>Basic sensor data</li>
			<li>30 days of data history</li>
			<li>Manual fault reporting</li>
			<li>Map view and email alerts</li>
			<li>Standard data export</li>
			<li>Business-hours support</li>
		</ul>
	</div>
	<div class="tier-card tier-advanced">
		<h3>Advanced</h3>
		<p><strong>Everything in Basic, plus:</strong></p>
		<ul>
			<li>Configurable alerts and threshold values</li>
			<li>Remote device management and diagnostics</li>
			<li>Map actions and view</li>
			<li>12 months of data history</li>
			<li>Advanced reports and analytics</li>
		</ul>
	</div>
	<div class="tier-card tier-pro">
		<h3>Pro</h3>
		<p><strong>Everything in Basic and Advanced, plus:</strong></p>
		<ul>
			<li>Unlimited data history</li>
			<li>Sub-tenant organization units</li>
			<li>Custom dashboards and reports</li>
			<li>Usage reports</li>
			<li>Priority technical support</li>
			<li>Agreed response times in accordance with the SLA</li>
		</ul>
	</div>
</div>

<div class="tier-pill-row">
	<span class="tier-pill">Basic: visibility</span>
	<span class="tier-pill">Advanced: control</span>
	<span class="tier-pill">Pro: customization</span>
</div>

## Capability Matrix

<div class="tier-matrix">

| Capability group | Basic | Advanced | Pro |
| --- | --- | --- | --- |
| Monitoring | Current device status and basic sensor data. | Remote device management and diagnostics. | Advanced monitoring with SLA-backed support response. |
| Alerts | Basic email alerts and manual fault reporting. | Configurable alerts and threshold values. | Priority technical support with agreed response times. |
| Data history | Last 30 days. | Last 12 months. | Unlimited history. |
| Reporting | Standard data export. | Advanced reports and analytics. | Custom dashboards, custom reports, and usage reports. |
| Map and organization | Map view. | Map actions and view. | Sub-tenant organization units. |
| Support | Business-hours support. | Business-hours support. | Priority technical support in accordance with the SLA. |

</div>
